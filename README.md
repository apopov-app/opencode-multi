# opencode-multi

Мультиагентные комнаты для [OpenCode](https://opencode.ai) V2: несколько моделей
общаются в одной обычной сессии, видят весь диалог и историю инструментов,
передают слово через `@упоминания` и могут проголосовать за остановку.

```
Вы:   Кто из вас лучше напишет тесты?
──────────────────────────────────────
Claude Haiku 5.5  Я бы начал с интеграционного…
                  @gpt, что скажешь?
GPT-6 Sol         Согласен, но добавлю property-based…
```

## Установка

Из GitHub:

```sh
opencode plugin add github:apopov-app/opencode-multi
```

Для проекта без глобальной установки скопируйте папку `.opencode/plugins/multi`
в проект — OpenCode подхватит её автоматически.

Перезапустите TUI/десктоп или выполните `opencode reload`. Плагин работает в
TUI, десктопе и веб-версии.

## Использование

1. В сессии выполните `/multi-room` — откроется выбор моделей (нативный диалог с
   чекбоксами, сгруппированный по провайдерам). Выберите минимум две.
2. Пишите как обычно: первая модель отвечает сразу, остальные подключаются в той
   же сессии.
3. Передача слова — `@handle`: `@gpt, что думаешь?`.
4. Остановка — кнопка прерывания/Esc, `/multi-room pause`, новое сообщение или
   голосование моделей через `room_stop` (комната встаёт, когда все за).
5. Если модели нужен ответ пользователя, она вызывает `request_input` — цепочка
   сразу завершается и ждёт вашего сообщения в чате, без голосования.

Команды:

```
/multi-room                      # выбор моделей
/multi-room model-a,model-b      # сразу с указанными моделями
/multi-room continue             # продолжить без нового сообщения
/multi-room pause | resume | off
```

В TUI `/multi` открывает поиск по моделям и меню комнаты.

Когда цепочка останавливается сама (лимит ходов или все проголосовали),
появляется диалог **Continue / Stop**: «Continue» запускает новую цепочку и
просит модели добавить новое, «Stop» прерывает текущий ход, очищает очередь
synthetic-ходов и оставляет комнату в покое.

Голоса хранятся в метаданных сессии и **копятся между прогонами**: если один
участник проголосовал, его голос не пропадёт со следующим сообщением. Сброс —
когда все проголосовали (стоп), при смене состава, паузе/выключении комнаты или
ручном `/multi-room continue`.

## Настройки

`.opencode/multi.json` (проект) или `~/.config/opencode/multi.json` (глобально):

```json
{
  "maxTurns": 50,
  "turnsPerModel": 0,
  "turnTimeoutMs": 240000,
  "providers": "auto"
}
```

- `maxTurns` — предохранитель от зацикливания (50 по умолчанию; `0` — без лимита).
- `turnsPerModel` — сколько реплик может сделать один участник (`0` — без лимита).
- `turnTimeoutMs` — таймаут одного хода (4 минуты).
- `providers` — `"auto"` (по умолчанию: все провайдеры, кроме бесплатного
  `opencode`, плюс провайдер текущей модели), `"current"` (только текущий),
  `"all"` (все, включая бесплатный `opencode`) или массив id провайдеров.

## Ограничения

- На сообщение первым отвечает модель, выбранная в сессии (изначально — первая
  из списка, после цепочки — последняя говорившая). Остальные подключаются после.
- Без `@упоминаний` участники идут по кругу; с упоминаниями слово переходит
  адресату.
- `@` в поле ввода OpenCode использует для файлов и агентов, поэтому при наборе
  может открыться список — Esc его закрывает.
- Смена модели видна в ленте строкой `Switched model to …`.
- Каждый участник и каждый ход — отдельный вызов модели, стоимость растёт.
